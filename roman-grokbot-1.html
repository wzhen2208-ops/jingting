🔧 1. 科技背景（10）
Lenny's Podcast
Lenny Rachitsky 的播客，硅谷最有影响力的产品/增长访谈节目之一，配套 Lenny's Newsletter（本集图文页见上方链接）。
Grok Bot · SpaceXAI
Grok Bot 是 SpaceXAI 推出的“知识工作代理”：一组在云端有自己电脑的 AI 机器人，能替你发邮件、做调研、操作网页。
Cursor
AI 写代码工具公司，Roman 是它的第 15 号员工；后被 SpaceX 收购，团队并入 SpaceXAI。
Cowork · Codex · ChatGPT
竞品：Cowork 是 Anthropic（Claude）的办公代理，Codex 是 OpenAI 的代理产品，ChatGPT 是 OpenAI 的聊天产品。
agent · bot 代理 / 机器人
能自己调用工具、分多步完成任务的 AI。本集里 bot 就是 Grok Bot 里的一个个 AI 同事。
onboarding 上手引导
带新用户/新员工上手。Grok Bot 团队早期亲自视频连线带了两三百人。
ship / unship
ship＝把功能上线发布；unship＝把已做的功能撤掉。本集核心观点之一：砍掉多余功能。
MCP · API
程序之间对接的接口。MCP 是让 AI 连接外部工具的协议。没有接口的软件，AI 只能像人一样看屏幕点鼠标（computer use）。
chain of thought · tool call
思维链＝模型一步步推理的过程；工具调用＝AI 去搜索、点网页、发消息等动作。Grok Bot 选择不展示这些。
WorkOS（广告）
7:28–8:40 的赞助商，为企业软件提供单点登录（SSO）、权限（RBAC）、审计日志等功能。
