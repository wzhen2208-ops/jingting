🔧 1. 科技背景（5）
主 bot（main bot）
以前大家都自己建一个“总助”bot，现在产品直接给每个人一个叫 Grok Bot 的主 bot。它会主动看你的邮件、日历、插件，发现问题就提醒或直接处理。
Origin、GitHub 和 PR
GitHub 和 Origin 是程序员存代码的平台；PR（pull request，拉取请求）是提交代码改动、请别人审核的申请。你不写代码也没关系，只要知道 bot 能帮工程师跟进这些。
Google 套件和 PPTX
Google 套件就是 Google 表格、文档、幻灯片；PPTX 是 PowerPoint 文件。现在 bot 能直接做好幻灯片发你 PPTX。
团队 bot 和 Slack
团队 bot 是可以共享给全团队的 bot；Slack 是公司常用的聊天软件，类似企业微信。thread（线程）是某条消息下面的讨论串。
Command K
Mac 上 Command 键加 K 的快捷键（Windows 通常是 Ctrl+K），用来调出搜索框。
