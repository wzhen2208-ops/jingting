🔧 1. 科技背景（10）
X Space：先适应直播问答
X Space 是 X 上的实时音频交流形式。本课按素材介绍，是 Matt Palmer 与 Eric Zakariasson 的首次 X Space Q&A，现场也在讨论画面和连接问题。问答会被插话、玩笑和读评论打断；精听时先找观众的问题，再追踪两人的回答。
两位说话者与公司称呼
Matt Palmer 在开场介绍自己属于 SpaceX AI 的 developer experience team；Eric Zakariasson 也参与产品构建。本课中的公司与产品关系按这次对话理解，中文保留 SpaceX AI、Grok Bot、Cursor 等名称。Matt 常以个人使用经历说明思路，Eric 补充搭建方式和新功能，两人并非每个问题都给出确定答复。
Grok Bot、connectors 与 routines
Grok Bot 是本课讨论的助手产品；connectors 让它接入外部信息或服务，routines 用于重复执行工作。Slack、Notion、Apple services 与 Microsoft Teams 分别提供不同协作或数据入口。需要区分接入信息、发起动作、持续运行这几层能力。
Vault 与 1Password
按现场说明，Vault 面向地址、电话、密码等敏感信息的保存与使用；bot 能代填，并不意味着模型直接取得其中的原始值。1Password 是另一个凭据管理产品，仍有企业用途和其他集成。两人把 Vault 描述为直接融入 Grok Bot 的轻量选择，而非宣布取代 1Password。
Pages：可分享的产物
本课中的 Pages 承载周报、网页、游戏、可视化报告和看板，不应与 Apple 的同名文字处理应用混淆。Eric 以带保留的语气描述其底层：React app 配合内部 SDK 和预制组件。重点是把多来源信息变成便于理解、分享和继续更新的产物。
Team Bots 与 Microsoft Teams
Team Bots 是供团队共享能力的产品名称；Microsoft Teams 是另一款协作产品，两者不能混为一谈。对话把 Team Bots 比作内部工具的新入口：原来必须请某人代办的查询或计算，可以让团队成员直接问 bot。有关 Microsoft Teams 的回答多次使用 I think，应保留这种不确定性。
Cursor projects 与 Cloud Agents
按 Matt 的使用介绍，Cursor projects 用一个对话入口协调多个 agents，在指定环境或 repo 中执行工作。安装 Cursor plugin 后，Grok Bot 可以找 Slack 背景信息并发给运行中的项目，也可收到项目回复。Cloud Agents 在本课中还承担接收反馈、修改代码的角色；与负责广泛信息接入的 Grok Bot 分工互补。
Scout：Eric 自己的简报 bot
Scout 是 Eric 给个人 bot 起的名字，任务是从 Slack、Notion 和其他项目中提炼公司动态，每天发送简报。它不是本课宣布的一款独立通用产品。signal 与 noise 在此分别指值得关注的信息和大量分散消息；Lily 可以类比为从生产记录中找出异常与重点。
X Money 与支付设想
X Money 是对话中的支付服务名称。两人讨论购物、一次性虚拟卡，也设想朋友分账与 bot 之间付费。注意区分用户已分享的用法与说话者正在畅想的 bot economy；例如分账问题的回答明确带有未确认语气。
Siri、Apple TV 与 computer use
Siri 是被拿来比较的语音助手；当时介绍的实际做法是用 action button 打开 Grok Bot 语音通话。Apple TV 展示 bot 产物、Apple Watch 使用 bot 都在讨论或建议层面。computer use 指 agent 经由电脑界面操作软件，本课明确区分已提到的 Cursor 能力与仍在推进的 Grok Bot 方向。
