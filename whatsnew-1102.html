🔧 1. 科技背景（7）
购物体验这条主线
本期围绕搜索商品、比较颜色和规格、结账付款、跟踪订单展开。carousel 是可左右滑动的商品卡片栏；checkout 是购物结账，不是酒店退房。
Vault 与支付服务
按视频介绍，Vault 是保存登录和付款资料的保险库。Matt 提到信用卡、Link、Shop Pay 和 X Money；这些名称在本课中保留英文。
Cursor 自定义智能体模式
agent mode 是给智能体规定工作方式的设置。Matt 说，为 Cursor 云端智能体指定的模式会带入运行过程，智能体会持续遵循。
Team Bots、Team Pages 与资料库
Team Bots 是团队使用的 bot。管理员保存的登录信息可供用户沿用；bot 能分享给团队或整个组织，也能在资料库置顶。Team Pages 则显示在对应 bot 下面，方便查找团队可视化内容。
Slack 连接器与例行任务
connector 用来连接外部服务，routine 指预先安排的例行任务。Team Bot 在 Slack 运行任务需要连接或批准时，可以直接在那里提问，用户也在那里处理。
联系资料与界面打磨
Vault 可保存多套联系信息，并选一套为主要资料，供 bot 安全地自动填入地址等表单。快速更新还包括 X 设置提速、页面多处同时编辑、Vault 工具栏统一风格。
海边口语与技术口语
Ocean Beach 是本期拍摄地点，湿脚和洗鞋是现场插曲。技术团队说 ship，常指发布功能；quality of life updates 指让操作更方便的改进；结尾 Peace 是随意说再见。

🧩 3. 疑难句（8）
#8So you'll be able to see products that you search for in a nice little carousel that shows you their availability, the stores you can find them in, different colors, etc.
你搜到的商品会显示在一个小小的轮播卡片栏里，能看到有没有货、哪些店有卖、有哪些颜色等等。
🧩 主干是 you'll be able to see products … in a … carousel；that you search for 修饰 products，that shows you … 修饰 carousel，后面列出供货情况、店铺和颜色。
#14So redesigned shopping experience in Grok Bot from everything to searching for a product to tracking an order that you've already placed.
也就是说，Grok Bot 的购物体验重新设计了，从搜商品到跟踪已经下好的订单，整个流程都覆盖到了。
🧩 So redesigned shopping experience 是省略式总结。from everything to searching … to tracking 搭配不整齐，按上下文理解为 everything from searching … to tracking …；不能照着原话当标准句型背。
#18You can store payment options in your Vault, whether that's a credit card — I've talked about Link payments in Grok Bot —
你可以把付款方式存进 Vault，比如信用卡——我之前也讲过 Grok Bot 里的 Link 支付——
🧩 whether that's a credit card 开始列举付款方式，却插入 I've talked about Link payments …，下一句再接 Shop Pay 和 X Money。不要等着听一个完整的 whether … or … 才理解。
#23So now if you specify what we're calling an agent mode for a cloud agent, a Cursor cloud agent, that's gonna carry over into the agent.
现在，如果你给云端智能体——也就是 Cursor 云端智能体——指定一个我们称作“智能体模式”的设置，这个设置就会带到智能体里。
🧩 if you specify … 是条件从句，what we're calling an agent mode 是 specify 的宾语；a Cursor cloud agent 补充说明 a cloud agent。主句从 that's gonna carry over 开始，that 指前面指定的模式。
#28And basically the secrets, files, other information associated with that bot is all going to come through with that login.
基本上，和这个 bot 关联的密钥、文件及其他信息，也都会随这套登录信息一并带过来。
🧩 the secrets, files, other information associated with that bot 是一长串主语；associated with … 修饰相关信息，come through with that login 表示随登录信息一起带过来。原话 is 与前面的列举不完全一致，是口语现象。
#34And our thinking here is basically, number one, let's make these things better to use across the organization and more granularly scoped, and two, easier to find, right?
我们的想法是：第一，让这些 bot 在整个组织里更好用，也能更细致地设置使用范围；第二，让大家更容易找到，对吧？
🧩 number one 引出两个并列目标 better to use 和 more granularly scoped；and two 后面省略 let's make these things，只剩 easier to find。right 是句尾确认语气。
#39So now if a bot needs permission, it needs to connect to something in order to run on a routine, it's going to ask you directly in Slack.
现在，如果 bot 运行例行任务需要权限、需要连接某个服务，它会直接在 Slack 里向你提出请求。
🧩 if a bot needs permission 后面又加 it needs to connect … 解释具体需求；in order to run on a routine 说明目的。真正的结果是 it's going to ask you directly in Slack。
#45You can save multiple contact information and then you can pick one as primary.
可以保存多套联系信息，再选一套设为主要信息。
🧩 information 是不可数名词，原话 multiple contact information 不规范，可理解为 multiple sets of contact information。pick one as primary 中 one 指其中一套联系资料，不是单个 information。
