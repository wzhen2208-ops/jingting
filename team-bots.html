🔧 1. 科技背景（6）
Team Bot
Grok Bot 是个人的 AI 助手；Team Bot 是复制一份给团队共享的版本（需团队版或企业版）。所有者能改设置，使用者只能用，像工厂里“工艺工程师写 SOP，操作工照着做”。
Slack 和 Microsoft Teams
两个最常见的公司聊天软件。把 Team Bot 装进去后，同事在群里 @它 就能用，不用另开 App。
技能、定时任务、密钥
技能（skill）是写给 bot 的做事说明；定时任务（routine）让它按时自动运行；密钥（secrets，如 API key）让它安全地登录别的系统。
API 和 Typefully
API 是程序之间对话的接口，API key 就是“通行证”。Typefully 是写作和定时发布社媒帖子的工具。
内部工具
公司自己做、自己用的工具：共享模板、Excel 表、宏、内部软件。Matt 认为 Team Bot 就是新一代内部工具，把一个人的经验复制给全团队。
瓶颈和孤岛
瓶颈（bottleneck）：所有事都要经过某人，他就卡住了整体产出。孤岛（silo）：每个人的 AI 聊天各自为政，经验无法共享。
