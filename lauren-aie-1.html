🔧 1. 科技背景（15）
Lauren Tan（@poteto，“土豆”）
SpaceXAI Grok Bot 工程负责人（主持人介绍为 SpaceX Super Intelligence 首席工程师），以前在 Netflix、Meta React 团队，也做过 Cursor 的代理功能。网名 Potato（土豆），所以开场说 my name is Potato。
AI Engineer CODE Summit
面向 AI 工程师的大会，2026 年 11 月在旧金山举行。本课是第 1 天上午主会场的最后一场演讲，官方还没有单独上传，只能从 9 小时直播里截取。
PR · pull request
程序员改完代码，提交一个“合并请求”，别人审查后合进主代码。PR 数量≈产出量。Lauren 上个月个人 3,000 个，整个 Grok Bot 团队 11,000 个。
slop · 垃圾代码
原意是泔水、粗劣的东西。AI 圈说 AI slop，指 AI 大量生成、质量差的内容或代码。题目 turn slop into gold＝把垃圾变黄金。
agent · AI 代理
能自己读代码、改代码、跑测试、开 PR 的 AI 程序。Lauren 说现在每个工程师都像带着几百上千个代理的团队。
deterministic check · 确定性检查
每次结果都一样、由程序自动判断对错的检查，比如 lint 规则、类型系统、编译器、测试。相反的是写在文档里、要靠理解和判断的“文字规则”（prose）。
lint rule · 代码规则检查
lint 工具自动扫描代码，发现不允许的写法就报错。Lauren 的核心做法：每次纠正代理，就加一条 lint 规则，让同样的错误以后根本写不进去。
AGENTS.md · rules · skills
写给 AI 代理看的说明文档、规则和技能包。Lauren 认为它们有用，但不可强制执行，所以放在倒金字塔最底层。
useEffect（React）
React 框架里一个常被误用的功能，需要很多经验才能用好。Grok Bot 直接在产品代码里禁止使用它，从根上消灭这类问题。
Electron · 主线程 / 渲染线程
Electron 用网页技术做桌面应用（Grok Bot、Cursor、VS Code 都是）。主线程（main）管系统，渲染线程（renderer）管界面；把主线程代码引进界面会造成卡顿（jank）。
Dune
Grok Bot 团队自己做的桌面客户端框架，可以理解为“给 Electron 用的 Next.js”，里面写进了很多约束和 lint 规则。
verification · 验证
证明代码真的做对了：运行时验证（让代理自己跑应用、截图、录视频）、形式化验证（用 TLA+、Lean 这类工具做数学式证明）、基于属性的测试（Bombadil 自动乱点界面找 bug）。
feature map · 功能地图
把应用里所有功能按用户视角列成“网站地图”，代理就不用猜“左边栏那个东西”指的是什么。
revert · 回滚
PR 合并后出了问题又撤回。Lauren 的数据：PR 数量暴涨，回滚率反而下降，稳定在约 0.5%。
outer loop · inner loop
内层循环＝写代码、测试、改的日常编码循环；外层循环＝在上面自动派发任务、批量跑代理的“工厂”。Lauren 提醒：内层循环产出垃圾，自动化只会产出更多垃圾。

每次纠正代理时，都想想能否把这条要求变成确定性的检查，而不是往规则或 AGENTS.md 里再添一行。

#136These are just good software engineering tools, but ones that might have been prohibitively expensive to use before as they were hard to understand or write or maintain.
它们都是成熟的软件工程工具，只是过去理解、编写或维护起来很难，使用成本可能高到难以承受。
🧩 These are just good software engineering tools, but ones that might have been prohibitively expensive to use before as they were hard to …：ones 代替 tools；might have been＝以前可能是；as 在这里＝because。

#158is that the performance of Grok Bot has stayed not just stable but has improved on multiple dimensions compared to when we launched.

🧩 is that the performance of Grok Bot has stayed not just stable but has improved on multiple dimensions：not just A but B（不只是稳定，还在多个方面提升）。主语在上一句：the really interesting thing … is that …。
