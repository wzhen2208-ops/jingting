🔧 1. 科技背景（10）
X 直播与主持人
视频说明写明，这是两人在 13 号星期五晚上做的 X 直播。Matt Palmer 做 SpaceX AI 的开发者体验工作，Lauren Tan 是 Grok Bot 团队的工程负责人，在 X 上用 @poteto。他们边读聊天留言边答，也会跟熟人打招呼、聊晚饭；听到问题时，可以先分清是在念观众原话还是两人自己在说。
Grok Bot 1.0 与会议 Bot
开场说当周发布了 Grok Bot 1.0。视频里说 Bot 可以代你加入 Google Meet 或 Zoom、记笔记、在会议聊天中回复。有人在会议里下指令时，它还能调用已经接好的工具，比如去 Notion 或 Slack 查资料。
用量、token、routine 与 Webhook
token 是模型处理文本时用的计量单位。视频里说可在 Usage and billing 按 Bot 看用量，定时任务的频率、工作量和放进上下文的大文件都会影响消耗。routine 到点运行；Webhook 由外部服务的事件触发。Lauren 提到团队在研究 MCP events 规范，设想有变化再唤起 Bot。
Bot 模板
两人说，可以在分享设置里把 Bot 做成模板，朋友拿到链接后可一键安装。视频里说公开模板不含私人信息。Lauren 举了自己分享的 Dr. Eggbot 和 TinkerBot，说明怎么复用别人做好的流程。
Slack 团队 Bot、技能与记忆
视频里说 Teams 或 Enterprise 账号可共享团队 Bot，Slack 讨论串里可以同时 @ 几个 Bot。Lauren 建议把重复步骤写成 skill，再用 Origin 或 GitHub 保存版本。她把更稳定地记住个人偏好当作团队正在改进的方向。
Cursor Cloud Agents 与协调调度
Lauren 把 Cursor Cloud Agents 比作有独立机器的临时帮手，负责具体代码任务。Matt 用 orchestrator 形容 Grok Bot 的角色：先汇总会议或应用里的信息，再启动专用代理，由它们保留各自任务所需的上下文。视频举了开发、发布和剪辑的例子。
Tailscale 与家庭网络
视频里说 Tailscale 集成可访问 tailnet 里的 MCP 服务。把 tailnet 理解成连接自己设备的私有网络，就容易听懂家中 Mac mini、Plex 歌单和打印机等例子。局域网设备能做什么，还要看设备本身提供哪些接口。
Vault 与密码
视频里说，Vault 提供专门的密码输入方式，按 Matt 的解释，Bot 不会直接看到密码。他也提醒不要把密码等敏感信息粘到聊天框或输入终端。两人讨论虚拟机备份时，还建议把长期要用的文件另存。
iPhone 操作按钮
视频里说，在有操作按钮的 iPhone 上，可以把它设为快捷指令并选择 Grok Bot 的语音入口。按住侧边按钮就能开始语音对话。听第 654–656 句时留意 shortcut 和 hold ... down。
直播里常见的口语与俚语
mog 是把别人比下去，本场用在身材和合照上；laptop-mogged 是 Matt 拿自己较小的电脑开玩笑。goated 是在说某样东西很顶，cooking 可形容团队正在忙着做出东西，yapping 是讲个不停。OG 用来叫早期支持者，shout out 是公开打招呼或致谢。
