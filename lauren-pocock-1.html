🔧 1. 科技背景（12）
Lauren Tan · @poteto
网名 Poteto（读音同 potato）。前 Netflix、Meta React 团队工程师，现在 SpaceXAI（原 Cursor）做代理窗口性能和 Grok Bot。10 天前的演讲讲她如何一个月发 2,500 个 PR。
Matt Pocock
英国开发者、TypeScript 教学名人（Total TypeScript），现在做 AI 编程技能和课程。本期是他的直播访谈。
Cursor · SpaceXAI
Cursor 是 AI 写代码工具，后被 SpaceX 收购，团队并入 SpaceXAI；Grok Bot 也出自这里。
agent 代理 · harness 外壳
代理＝能自己调用工具、多步干活的 AI；外壳＝包住模型、给它工具和规则的程序（如 Claude Code、Cursor）。
skill 技能 · pstack
技能＝写给代理的“操作说明＋工具包”。pstack 是 Lauren 的技能库（how、why、unslop、create-verification 等），见上方原文链接框里的 GitHub 链接。
PR · ship to production
PR（pull request）＝一次代码修改申请；ship to production＝发布到正式环境给用户用。
trust ladder 信任阶梯
越信任 AI，就交给它越大、越多的活：从一步步盯着，到让它自己合并代码。
verification 验证
让代理自己运行程序、像用户一样点、看结果、抓日志——相当于给它“手和眼”，不用你当中转。
loop · hill climbing
循环＝做→验→改→再做（像 PDCA）；爬山法＝有个评分标准，每次小改只留得分更高的版本。
CLI · deterministic
命令行工具；确定性＝同样输入必得同样结果（适合写成脚本），与需要判断的工作相对。
context window 上下文窗口
模型一次能记住的文字量。满了要“压缩/总结”，以前压缩后代理常变笨。
software factory · Michelin kitchen
软件工厂＝用大批代理流水线式产出代码的热词；Lauren 更喜欢“米其林厨房”：强调品质和手艺。
