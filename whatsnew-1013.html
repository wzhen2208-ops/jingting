🔧 1. 科技背景（6）
Grok Bot 的邮箱
以前 Grok Bot 只能用你的 Gmail/Outlook 替你发邮件；现在它可以有自己的独立地址，像新员工领工号一样领一个邮箱名，用来注册服务、接收简报，不占你的邮箱。
X 和 API 密钥
X（原 Twitter）的开发者 API 要申请密钥、按调用付费。这次 Grok Bot 内置了 X 读取，不用你的账号和密钥，也不扣额度。
Shopify 和代发货
Shopify 是全球最常用的网店平台。代发货（drop shipping）是自己不囤货、客户下单后由工厂直接发货的模式，很多泰国、中国工厂就是这类卖家的供应商。
bot 的电脑
Grok Bot 每个智能体都有一台云端电脑，用来开浏览器、截图、录屏。屏幕分辨率越高，截图越清楚，就像品检相机像素越高越容易看清缺陷。
PR 和定时任务
PR（pull request）是程序员提交代码修改的请求；定时任务（routine）是让 bot 按时间自动做事，比如每天早上发日报。
国际化 i18n
internationalization 太长，常写成 i18n（i 和 n 之间有 18 个字母），指让软件支持多种语言和地区格式。
