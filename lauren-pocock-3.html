🔧 1. 科技背景（10）
代码园艺 gardening
不加新功能，而是持续清理、重构、修小问题，让代码库保持健康——类似工厂 5S。
cron job · routine
cron＝Unix 的定时任务；routine＝Grok Bot 里按计划自动运行的任务。
React · footgun
React＝Meta 的界面库，Lauren 曾在 React 团队；footgun＝容易让人“打到自己脚”的坑。
黑灯工厂 dark factory
全自动、无人在场、可以关灯的工厂。Lauren 说她的代理在她睡觉时自己合并代码，所以“算是”。
full autopilot · verifier · fuzzing
pstack 的全自动模式：为每个 PR 派多个验证代理，做模糊测试（像真人乱点）找回归问题，自己修，直到能合并。耗 token，可调。
SEV
大公司对线上事故的叫法（severity），SEV1 最严重。Lauren 怕第一天就“引发事故”。
Karpathy · vibe coding
Andrej Karpathy（前特斯拉 AI 负责人）提出“氛围编程”：只跟 AI 说话，几乎不看代码。Matt 说 Lauren 正相反。
单向门 / 双向门
贝索斯的说法：双向门＝可逆的决定，可以退回；单向门＝不可逆。
形式化证明 · Lean · TLA+ · Bend
用数学方法证明代码正确。Lean、TLA+ 是传统的证明语言；Bend 是 Lauren 提到的新语言（字幕拼写 B-E-N-D，具体是哪个项目不确定）。
skills · pstack · Wayfinder · Poteto mode
skills＝写给代理的流程说明文档。pstack＝Lauren 的技能库（含 Recall、全自动模式等）；Wayfinder、grill-me＝Matt 的技能；Poteto mode＝Lauren 的模式（Poteto 是她的网名）。
